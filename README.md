# Sales Tracker

Simple sales tracker for reselling snack packs. Add a sale, see your profit, and know when each customer is due to order again.

Open `index.html` in a browser, or deploy to any static host. Data saves in the browser (localStorage) on the device you use it on.

## The formula
- 1 pack $30 · 2 packs $55 · 3 packs $80 · 4 packs $105 · +$25 per extra pack
- Order every other week, or stop selling to them
- Prices can be negotiable, never below $25 a pack, after 5 purchases only
- No refunds
